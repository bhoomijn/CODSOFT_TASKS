
# 🔐 Password Generator | Python

A customizable Password Generator developed using Python as part of the **CodSoft Python Programming Virtual Internship – Task 3**.

This application generates random passwords based on user-defined length and selected character types, helping users create stronger and more varied passwords.

## 🚀 Project Overview

The Password Generator is a command-line application that allows users to generate passwords by selecting their preferred character combinations.

Users can include lowercase letters, uppercase letters, numbers, and special characters to customize password complexity.

## ✨ Features

- Custom password length.
- Lowercase letter support (a-z).
- Uppercase letter support (A-Z).
- Numeric characters (0-9).
- Special characters.
- Customizable password complexity.
- Secure random character selection using Python's `secrets` module.
- Input validation and error handling.

## 🛠️ Technologies Used

- Python 3
- `string` module
- `secrets` module
- Functions
- Conditional Statements
- Loops
- Exception Handling
