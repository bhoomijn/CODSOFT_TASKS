
# 📒 Contact Book Application | Python

A menu-driven Contact Book Application developed using Python as part of the **CodSoft Python Programming Virtual Internship – Task 5**.

## 🚀 Project Overview

The Contact Book is a command-line application designed to manage personal contact information efficiently. It allows users to store, search, view, update, and delete contact details.

The application uses JSON-based file handling to save contact information permanently, ensuring that data remains available even after restarting the program.

## ✨ Features

- **Add Contact:** Store name, phone number, email, and address.
- **View Contacts:** Display all saved contacts.
- **Search Contact:** Find contacts using their name or phone number.
- **Update Contact:** Modify existing contact information.
- **Delete Contact:** Remove unwanted contacts.
- **Persistent Storage:** Save contact details using JSON.
- **Input Validation:** Handle empty fields and invalid selections.
- **Error Handling:** Manage file and input-related errors.

## 🛠️ Technologies Used
