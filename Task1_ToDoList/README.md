
# 📝 To-Do List Application | Python

A simple yet practical **Command-Line To-Do List Application** developed using Python as part of the **CodSoft Python Programming Virtual Internship**.

This application helps users manage their daily activities efficiently by allowing them to add, view, update, and delete tasks. It also uses JSON-based file handling to ensure that tasks remain saved even after the application is closed.

## 🚀 Project Overview

The To-Do List Application is designed to make everyday task management simple and organized. Users can interact with the application through a menu-driven command-line interface.

The project demonstrates the practical implementation of Python programming concepts, including functions, lists, loops, exception handling, and file management.

## ✨ Features

- **Add Tasks:** Add new tasks to your personal to-do list.
- **View Tasks:** Display all saved tasks with serial numbers.
- **Update Tasks:** Modify existing tasks whenever required.
- **Delete Tasks:** Remove completed or unnecessary tasks.
- **Persistent Storage:** Automatically save tasks in a JSON file.
- **Input Validation:** Prevent empty task entries and handle invalid inputs.
- **Error Handling:** Handle file-related errors and invalid user entries.
- **User-Friendly Interface:** Simple menu-driven navigation.
