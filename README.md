# CODSOFT Python Programming Internship

This repository contains the Python projects completed as part of my **Python Programming Internship at CodSoft**.

The projects are developed using Python and focus on strengthening programming fundamentals, logical thinking, problem-solving, and practical application development.

## Projects

### Task 1: To-Do List Application
A command-line application to manage daily tasks.

**Features:**
- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Save tasks using JSON file storage

**Technologies:** Python, JSON

### Task 2: Calculator
A simple command-line calculator that performs basic arithmetic operations.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

**Technologies:** Python

### Task 3: Password Generator
A password generator that creates random passwords based on user preferences.

**Features:**
- Custom password length
- Lowercase letters
- Uppercase letters
- Numbers
- Special characters
- Secure random password generation

**Technologies:** Python, `secrets`, `string`

### Task 4: Rock Paper Scissors Game
A command-line game where the user plays Rock Paper Scissors against the computer.

**Features:**
- User input
- Random computer selection
- Winner determination
- Score tracking
- Option to play multiple rounds

**Technologies:** Python, `random`

### Task 5: Contact Book Application
A contact management application to store and manage contact information.

**Features:**
- Add contacts
- View saved contacts
- Search contacts
- Update contact details
- Delete contacts
- Save contacts using JSON file storage

**Technologies:** Python, JSON

## Requirements

- Python 3.x
- Any Python-supported code editor (VS Code, PyCharm, etc.)

No external libraries are required for the core projects.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/bhoomijn/CODSOFT_TASKS.git
```

2. Open the repository folder:

```bash
cd CODSOFT_TASKS
```

3. Open the required task folder and run its Python file.

Example:

```bash
cd Task1_ToDoList
python todo.py
```

Use the corresponding Python filename for the other tasks.
