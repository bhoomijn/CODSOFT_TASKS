
# 🎮 Rock-Paper-Scissors Game | Python

An interactive command-line Rock-Paper-Scissors game developed using Python as part of the **CodSoft Python Programming Virtual Internship – Task 4**.

## 🚀 Project Overview

This project is a simple interactive game where the user plays Rock-Paper-Scissors against the computer.

The computer randomly selects one of the three choices, and the winner is determined using predefined game rules. The application also maintains scores across multiple rounds.

## ✨ Features

- User selection: Rock, Paper or Scissors.
- Random computer selection.
- Automatic winner determination.
- Score tracking for the user and computer.
- Tie counter.
- Multiple rounds of gameplay.
- Play Again functionality.
- Invalid input handling.

## 🛠️ Technologies Used

- Python 3
- Random Module
- Functions
- Conditional Statements
- While Loop
- Lists
- User Input and Output

## ⚙️ How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python game.py
```

## 🎯 Game Rules

| Choice | Beats |
|---|---|
| Rock | Scissors |
| Paper | Rock |
| Scissors | Paper |

If both the user and computer select the same option, the round is declared a tie.
