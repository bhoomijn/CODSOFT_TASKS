
# 🧮 Calculator Application | Python

A simple and interactive command-line calculator developed using Python as part of the **CodSoft Python Programming Virtual Internship – Task 2**.

## 🚀 Project Overview

This calculator performs basic arithmetic operations through a menu-driven interface. Users can enter two numbers, select an operation, and instantly view the calculated result.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Supports integer and decimal inputs
- Handles division by zero
- Validates invalid numerical inputs
- Provides continuous calculations until the user exits

## 🛠️ Technologies Used

- Python 3
- Functions
- Conditional Statements
- Loops
- Exception Handling
- User Input and Output

## 📂 Project Structure

## ⚙️ How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python calculator.py
```

## 💻 Available Operations

| Choice | Operation | Symbol |
|---|---|---|
| 1 | Addition | + |
| 2 | Subtraction | - |
| 3 | Multiplication | * |
| 4 | Division | / |
| 5 | Exit | - |

## 📸 Sample Output
